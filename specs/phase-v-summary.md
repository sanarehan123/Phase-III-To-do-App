# Phase V Summary

## What Was Built
A fully cloud-native Todo application with AI chatbot,
deployed across multiple cloud platforms using Docker containers.

## Live URLs
- Frontend: https://phase-iii-to-do-app.vercel.app
- Backend: https://sanashakeel0821-todo-backend-phase3.hf.space
- GitHub: https://github.com/sanarehan123/Phase-III-To-do-App

## Phases Completed
- Phase II: Full-stack web app (FastAPI + Next.js + PostgreSQL)
- Phase III: AI Chatbot (Groq LLaMA + Function Calling)
- Phase IV: Containerization (Docker + Kubernetes configs)
- Phase V: Cloud deployment (Hugging Face Docker + Vercel)

## Key Technologies
- Frontend: Next.js 15, TypeScript, Tailwind CSS
- Backend: FastAPI, SQLModel, Python
- Database: Neon Serverless PostgreSQL
- AI: Groq LLaMA 3.3 70B with Function Calling
- Auth: JWT tokens
- Containers: Docker (running on Hugging Face)
- Orchestration: Kubernetes configuration files
- Cloud: Hugging Face Spaces, Vercel, Neon
