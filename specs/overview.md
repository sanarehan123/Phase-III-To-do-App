# Todo App — Phase II Overview

## Purpose
A multi-user todo web application with persistent storage and JWT authentication.

## Phase
Phase II: Full-Stack Web Application

## Tech Stack
- Frontend: Next.js 15 (App Router), TypeScript, Tailwind CSS
- Backend: Python FastAPI
- ORM: SQLModel
- Database: Neon Serverless PostgreSQL
- Auth: JWT tokens (Better Auth pattern)

## Features Implemented
- [x] User signup and signin with JWT authentication
- [x] Create tasks with title and optional description
- [x] View all tasks (filtered by status)
- [x] Edit task title and description
- [x] Delete a task
- [x] Mark task complete / incomplete
- [x] Tasks are private per user
